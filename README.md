# Дипломы HAMLOG

Независимое расширение UB3DQY для HAMLOG.online. Оно сверяет каталог с уже выданными дипломами, помогает получить новые бесплатные дипломы и скачивает ранее выданные.

- [Скачать для Chrome и Edge](https://github.com/ub3dqy/hamlog-awards-edge/releases/latest/download/hamlog-awards-edge.zip)
- [Скачать для Яндекс Браузера](https://github.com/ub3dqy/hamlog-awards-edge/releases/latest/download/hamlog-awards-yandex.crx)
- [Скачать для Firefox](https://github.com/ub3dqy/hamlog-awards-edge/releases/latest/download/hamlog-awards-firefox.xpi)
- [Выпуски и контрольные суммы SHA-256](https://github.com/ub3dqy/hamlog-awards-edge/releases)
- [Сайт разработчика UB3DQY](https://ub3dqy.com/)

## Установка

- **Chrome и Edge.** Распакуйте общий ZIP. Откройте `chrome://extensions/` или `edge://extensions/`, включите режим разработчика и загрузите папку с `manifest.json` через «Загрузить распакованное».
- **Яндекс Браузер.** Откройте `browser://tune` и перетащите на страницу скачанный CRX.
- **Firefox 140 и новее.** Скачайте подписанный Mozilla файл XPI. Откройте `about:addons`, нажмите на шестерёнку и выберите «Установить дополнение из файла». Откройте скачанный XPI и подтвердите установку.

В **«Настройках»** расширения сохраните позывной из раздела HAMLOG «Мои позывные». Затем откройте свой кабинет HAMLOG и нажмите значок «Дипломы HAMLOG».

## Дипломы

- **Проверить дипломы** сверяет все страницы каталога с разделом «Мои полученные дипломы». Отдельно видны выданные дипломы и программы без записи о выдаче. Список без записи включает и невыполненные, и ещё не выданные программы. HAMLOG может сразу выдать диплом при проверке условий по позывному, поэтому первая кнопка страницы программ не открывает.
- **Получить и скачать новые** открывает программы по очереди. HAMLOG проверяет условия и выдаёт подходящие дипломы. Расширение сверяет новые записи, скачивает бесплатные электронные дипломы в PDF и собирает несколько файлов в ZIP. Большая подборка делится на части. Повторное нажатие кнопки в той же вкладке продолжает скачивание оставшихся файлов. В панели остаётся ссылка на последний готовый файл или архив.
- **Скачать выданные** читает раздел «Мои полученные дипломы» выбранного позывного. Большая подборка сохраняется частями, и расширение само переходит к следующей части. Если браузер пропустит загрузку, скачайте нужную часть из панели. Старые части можно собрать заново. После остановки можно продолжить в той же вкладке.

Полный проход по каталогу может занять 20 минут или дольше. Оставьте вкладку HAMLOG открытой и оставайтесь в своём кабинете. В панели есть кнопка остановки. Изменение позывного применяется при следующем запуске. Выданные дипломы остаются доступны в разделе «Мои полученные дипломы».

Если у программы особая форма, сайт не показывает результат выбранного позывного или не подтверждает бесплатное скачивание, это будет указано в отчёте. Если расширение распознало адрес программы, в отчёте появится ссылка для ручной проверки.

## Обновления

В Firefox начиная с версии 1.3.2 новые подписанные выпуски устанавливаются автоматически, когда в браузере включены обновления дополнений. Если установлена версия 1.3.1 или более ранняя, один раз установите текущий подписанный XPI через `about:addons`.

В Chrome и Edge распакуйте новый ZIP в прежнюю папку и нажмите «Перезагрузить» на карточке расширения. В Яндекс Браузере перетащите новый CRX на `browser://tune`. В настройках расширения можно проверить наличие выпуска вручную. После обновления перезагрузите вкладку HAMLOG.

## Данные

Позывной хранится в текущем профиле браузера. После запуска команды расширение обращается к `hamlog.online` в рамках открытого кабинета. Браузер использует обычный сеанс HAMLOG. Для проверки дипломов HAMLOG получает позывной, а для сохранения PDF получает обратно имя и защитный код из своей формы. Расширение не запрашивает пароль и не заполняет платёжные формы. Для обновлений оно отдельно запрашивает публичные сведения о выпусках у `api.github.com` без позывного и данных кабинета.

## Сборка выпуска

1. В чистой копии репозитория выполните `python tools/build_release.py --firefox-only --output firefox-upload`. Нужен Python 3.10 или новее. Эта команда подходит для Windows и Linux и создаёт ZIP для отправки в Mozilla.
2. В кабинете Mozilla выберите распространение на своём сайте («On your own») и отправьте `firefox-upload/hamlog-awards-firefox.zip`. К заявке приложите исходники этой версии. После проверки скачайте подписанный XPI и проверьте установку через `about:addons` в обычном Firefox.
3. Из той же версии исходников соберите все пакеты командой `python tools/build_release.py --output release --yandex-key <закрытый-ключ.pem> --signed-firefox <файл-Mozilla.xpi>`. Для этого шага нужен OpenSSL. Используйте один и тот же закрытый RSA-ключ для всех выпусков Яндекс Браузера и храните его вне репозитория.
4. В черновик выпуска GitHub добавьте три пакета, `SHA256SUMS.txt` и `updates.json` из папки `release`. Используйте тег `v` с номером версии, например `v1.3.3`. Опубликуйте полный выпуск как последний стабильный. Firefox берёт адрес подписанного XPI и его SHA-256 из `updates.json` последнего выпуска.
