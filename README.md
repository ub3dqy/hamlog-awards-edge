# Дипломы HAMLOG для Microsoft Edge

Независимое расширение UB3DQY для HAMLOG.online. Оно сверяет каталог с уже выданными дипломами и помогает получить новые бесплатные электронные дипломы.

- [Скачать ZIP](https://github.com/ub3dqy/hamlog-awards-edge/releases/latest/download/hamlog-awards-edge.zip)
- [Выпуски и контрольные суммы SHA-256](https://github.com/ub3dqy/hamlog-awards-edge/releases)
- [Сайт разработчика UB3DQY](https://ub3dqy.com/)

## Установка

1. Скачайте ZIP из GitHub Releases и распакуйте его в папку, где будут храниться файлы расширения.
2. Откройте `edge://extensions/`, включите «Режим разработчика» и нажмите «Загрузить распакованное». Выберите папку, в которой находится `manifest.json`.
3. Откройте «Дипломы HAMLOG» через значок расширений в Edge. В **«Настройках»** введите позывной и нажмите **«Сохранить»**. Можно использовать основной или другой позывной из раздела HAMLOG «Мои позывные», в том числе с `/`, дефисом или пробелом.
4. Откройте свой кабинет HAMLOG и снова нажмите значок «Дипломы HAMLOG».

[Инструкция Microsoft по загрузке локального расширения](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)

## Две кнопки

- **Проверить дипломы** сверяет все страницы каталога с разделом «Мои полученные дипломы». Отдельно видны выданные дипломы и программы без записи о выдаче. Список без записи включает и невыполненные, и ещё не выданные программы. HAMLOG может сразу выдать диплом при проверке условий по позывному, поэтому первая кнопка страницы программ не открывает.
- **Получить и скачать новые** открывает программы по очереди. HAMLOG проверяет условия и выдаёт подходящие дипломы. Расширение сверяет новые записи, скачивает бесплатные электронные дипломы в PDF и собирает несколько файлов в ZIP. Большая подборка делится на части. Повторное нажатие кнопки в той же вкладке продолжает скачивание оставшихся файлов. В панели остаётся ссылка на последний готовый файл или архив.

Полный проход по каталогу может занять 20 минут или дольше. Оставьте вкладку HAMLOG открытой и оставайтесь в своём кабинете. В панели есть кнопка остановки. Изменение позывного применяется при следующем запуске. Выданные дипломы остаются доступны в разделе «Мои полученные дипломы».

Если у программы особая форма, сайт не показывает результат выбранного позывного или не подтверждает бесплатное скачивание, это будет указано в отчёте. Если расширение распознало адрес программы, в отчёте появится ссылка для ручной проверки.

## Обновления

Расширение проверяет наличие новых стабильных выпусков на GitHub. В настройках можно запустить проверку вручную. При наличии новой версии скачайте ZIP, распакуйте его в ту же папку и нажмите «Перезагрузить» на карточке расширения в `edge://extensions/`. Затем обновите вкладку HAMLOG. При сохранении той же папки настройки профиля Edge сохраняются.

## Данные

Позывной хранится в локальном хранилище расширения в текущем профиле Edge. Запросы по дипломам отправляются только на `hamlog.online` в рамках открытого кабинета. Расширение не запрашивает пароль и не заполняет платёжные формы. Для обновлений оно отдельно запрашивает публичные сведения о выпусках у `api.github.com` без позывного и данных кабинета.
